# Темы и вопросы

## Тема

**Тема (`Topic`)** — структурная категория для группировки вопросов по предметной области.

Тема может иметь родительскую тему (`parentId`), что позволяет формировать иерархию любой глубины. `sortOrder` определяет порядок отображения тем на одном уровне.

Пример:

```text
Java
├── Core
├── Collections
├── Exceptions
└── Spring
    ├── Spring Core
    └── Spring Boot
```

Тема имеет жизненный цикл: `DRAFT → PUBLISHED → ARCHIVED`.

## Вопрос

**Вопрос (`Question`)** — основной учебный контент, относящийся к одной теме.

Вопрос содержит:

* текст вопроса;
* ответ;
* необязательное объяснение;
* уровень сложности;
* уникальный `slug`;
* статус публикации.

Каждый вопрос принадлежит одной теме через `topicId`.

Вопрос также проходит жизненный цикл: `DRAFT → PUBLISHED → ARCHIVED`.

## Идентификаторы

`UUID` используется как технический идентификатор сущности и для связей между сущностями.

`slug` — стабильный человекочитаемый идентификатор, предназначенный для публичных URL и навигации.

## Публикация

Черновики доступны только через административный API. В публичный API попадают только опубликованные вопросы и темы.
